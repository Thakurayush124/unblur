# Guide characters

These sprite sheets come from [page-mascot](https://github.com/nilbuild/page-mascot) by
[Kamran Ahmed](https://kamran.fyi), used under the MIT License (see `LICENSE` in this folder).

Each character is two 3×3 sheets: `*-directions.webp` (nine head directions, used to follow
the cursor) and `*-reactions.webp` (nine expressions shown when it is clicked). They are
rendered with the `page-mascot` React component.
